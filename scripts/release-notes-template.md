## Install

Download **Swoop-__VERSION__.dmg** below, open it and drag Swoop to Applications. Swoop needs macOS 14 or later and runs natively on Apple silicon and Intel.

Already using Swoop? It updates itself: choose **Swoop → Check for Updates…**. Every update is verified against Swoop's Ed25519 release key (`Swoop-__VERSION__.dmg.sig`) before it's installed.

Releases are not yet notarized, so macOS asks for confirmation the first time. Control-click Swoop in Applications and choose **Open** (or allow it under System Settings → Privacy & Security), or run `xattr -dr com.apple.quarantine /Applications/Swoop.app`.
